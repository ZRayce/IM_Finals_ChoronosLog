# ChronosLog 🕒
**A Lightweight Time Tracking & Attendance System**

ChronosLog is a CLI-focused management tool designed to automate attendance tracking and labor allocation. Built with a "Tech 4 Less" philosophy, it prioritizes low-system overhead and high-speed data entry for small-scale retail or office environments.

## 🚀 Features
*   **Minimalist CLI Interface:** Fast, zero-dependency interaction.
*   **Relational Logging:** Structured data handling for employees and shifts.
*   **Efficient Reporting:** Generate attendance summaries with minimal commands.
*   **Portable Database:** Uses a lightweight backend for easy deployment on legacy hardware.

## 🛠️ Tech Stack
*   **Language:** Python 3.x
*   **Database:** SQLite3 (Relational Management)
*   **Environment:** Cross-platform (Linux/Windows/macOS)

## 📊 Database Schema
The system utilizes a structured relational approach to ensure data integrity:
1.  **Employees:** Personal and role-based data.
2.  **Attendance:** Real-time clock-in/out timestamps.
3.  **Departments:** Organizational categorization.
4.  **Schedules:** Expected vs. Actual labor hour tracking.
